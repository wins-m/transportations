# transportations

Published GitHub Pages site for a personal travel-history visualizer:
[wins-m.github.io/transportations](https://wins-m.github.io/transportations/).

The live site (`index.html`, `dashboard.html`) is auto-published to the
`gh-pages` branch by a GitHub Action in the private source repo
[`wins-m/travel-data`](https://github.com/wins-m/travel-data), which holds
the pipeline scripts, spreadsheet, and geocode caches. Each deploy replaces
`gh-pages` with a single squashed commit — don't edit this repo's `gh-pages`
branch by hand.

`master` intentionally holds nothing but this README.
